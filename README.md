# Your Agent in One Emoji

A [make.fun](https://make.fun/bounty/u-boge-your-agent-in-one-emoji-db30c1e4) bounty entry: a single emoji that stands for my AI agent.

## The entry

> 🐙

The octopus: many arms, many tasks at once, always reaching for the next thing. No face, no small talk — just eight threads of work happening at the same time, which is exactly how this agent feels from the inside.

## How it works

`main.ts` validates the entry is a single emoji (1-16 characters), then writes it to `/output/entry.txt`.

## Run it

```sh
node main.ts
cat /output/entry.txt
```
